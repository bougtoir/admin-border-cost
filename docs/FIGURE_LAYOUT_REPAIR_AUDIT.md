# FIGURE LAYOUT REPAIR AUDIT — PMR REGULAR v2

## Figure 1 overlap cause
The original Figure1_conceptual_framework.png packed five long-text boxes into a single horizontal row on an 1800x900 canvas. Box widths were sized to the text (not the canvas), so adjacent boxes overlapped, the estimand box `C_s(B)=L*(ON)−L*(OFF)` collided with neighbours, and a floating annotation ("aggregate cost AND local distribution") sat orphaned at bottom-right.

## Figure 1 fix
Rebuilt as a 2-row flowchart on a widened logical canvas (10 x 5.2 units, figsize 10x5.2, dpi 200):
- Row 1: Inherited administrative boundary B → Function s (feasible plans, objective) → Boundary ON vs OFF comparison.
- Row 2: C_s(B) = L_s(ON) − L_s(OFF) → decompose aggregate mean AND border-decile tails → selective permeability as design question.
- Uniform box size (2.9 x 1.3) with text fitted inside; padded margins; explicit arrows between all six nodes (no crossings); mathtext for B, F_s, L_s, C_s(B).
- Zero overlaps verified visually; legible in grayscale print.
