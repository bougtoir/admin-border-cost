# SEPS targeting notes (2026-10-02)

## Fit rationale

Socio-Economic Planning Sciences is "The International Journal of Public
Sector Decision-Making": it publishes quantitative (OR/MS, statistical)
analysis of public-sector planning problems. The retargeted manuscript is
framed as exactly that — territorial alignment of public functions is a
constrained-planning decision whose opportunity cost C(B) = L*_B − L*_0
can be measured. The Kyoto–Shiga electoral-district case is the empirical
test bed; the contribution to SEPS is the paired-optimization estimand and
the demonstration that visible administrative–functional mismatch does not
by itself establish inefficiency.

## Conceptual reframing applied

- General frame added (Section 2): multiple public functions s = 1..S with
  potentially different efficient territories; alignment as a restriction
  F_B ⊂ F_0; opportunity cost on true minima; benefits-vs-cost decision
  problem. All multi-service content is labeled conceptual, not empirical.
- Introduction resequenced: overlapping territorial systems → mismatch
  treated as defect → alignment = constraint with opportunity cost →
  formal estimand → electoral districting as clean test bed →
  Kyoto–Shiga → contributions (methodological contribution made explicit).
- Discussion layered: empirical → mismatch-reform implication → general
  planning principle (calibrated language) → transferability examples
  flagged as future applications only.
- Resource-scarcity message integrated in discussion and conclusion;
  explicit disclaimer that transition/coordination costs are NOT
  estimated.
- Claim discipline enforced: no "mismatch is efficient", "fragmentation
  improves efficiency", "service areas should not align" wording.
