# Applied Geography — author rules (checked 2026-09-24)

Sources: sciencedirect.com/journal/applied-geography (aims & scope, APC,
metrics) and Elsevier guide for authors summary.

- Aims/scope: geographic approaches to human problems with a spatial
  dimension — GIScience work fits; applied geography contribution must lead.
- Article type: Research article, 4,500–8,000 words inclusive
  (captions/tables/references).
- Abstract: unstructured, ~250 words. (Current draft over → trim at packaging.)
- Keywords: 1–7.
- References: APA 7th edition, author–year in text (convert numbered list).
- Highlights: 3–5 bullets, ≤85 chars each (trim current bullets).
- Peer review: double-anonymized — main manuscript must not identify authors;
  keep author info in title page only (separate file).
- Declarations required: ethics (n/a — public aggregate data, mark "not
  applicable"), competing interests, funding (state none if unfunded),
  data availability (link repo), CRediT authorship roles.
- Figures: separate files, publication-ready, cited in order in text
  (F1–F7 cited sequentially — done).
- Supplement: uploaded separately.
- APC: USD 3,060 open access; subscription option free.
- Submission portal: submit.elsevier.com/JAPG.
- Do NOT state JIF/quartile in manuscript — only scope fit.
